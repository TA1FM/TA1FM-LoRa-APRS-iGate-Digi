Firmware yükleme / Install firmware

Yüklenecek sürümü seçin / Select version

Seçilen / Selected: V1.5.8

  1. Heltec Wireless Stick Lite V3 kartına uygun anteni bağlayın ve USB veri kablosunu takın.
  2. Sürümü seçip INSTALL FIRMWARE butonuna basın.
  3. Doğru COM portunu seçin ve yüklemeyi onaylayın.
  4. İşlem tamamlanınca cihazı yeniden başlatın.
Önemli / Important: Bu işlem mevcut firmware'i değiştirir ve kayıtlı Wi-Fi/APRS ayarlarını silebilir. Yedek alın. Eski sürüme dönüşte ayar uyumluluğu garanti değildir. Yalnızca Heltec Wireless Stick Lite V3 içindir. USB bağlantısını kesmeyin.
Web Serial desteklenmiyor. Windows, macOS veya Linux üzerinde güncel Chrome/Edge kullanın. Bu sayfa HTTPS üzerinden açılmalıdır.

İlk kurulum / First setup

Cihazda kayıtlı Wi-Fi ayarı yoksa kurulum ağı oluşturulur.

Wi-Fi: TA1FM-APRS-SETUP
AP parolası: 1234567890
Kurulum: http://192.168.4.1

Varsayılan yönetici kullanıcı adı: admin. Yönetici parolası, yüklediğiniz firmware paketinin kaynak kodundaki varsayılan değere bağlıdır; bunu kullandığınız sürümün yayımlanan kaynak kodundan kontrol edin ve kurulumdan sonra değiştirin.
