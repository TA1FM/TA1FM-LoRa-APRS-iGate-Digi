Web Installer

Heltec Wireless Stick Lite V3 cihazınıza TA1FM firmware yazılımını Chrome veya Edge tarayıcısından USB bağlantısıyla yükleyin. Arduino IDE gerekmez.

V1.5.7.1 · ESP32-S3 + SX1262

Firmware yükleme / Install firmware

  1. Heltec Wireless Stick Lite V3 kartına uygun anteni bağlayın; kartı veri aktarabilen USB kablosuyla bilgisayara takın.
  2. Chrome veya Edge tarayıcısında aşağıdaki INSTALL düğmesine basın.
  3. Doğru seri portu seçin, açılan penceredeki uyarıları okuyun ve yüklemeyi onaylayın.
  4. İşlem bittikten sonra cihazı yeniden başlatın.
Önemli / Important: Bu kurulum mevcut yazılımı değiştirir ve kayıtlı Wi-Fi/APRS ayarlarını silebilir. Yüklemeden önce ayarlarınızı yedekleyin. Bu paket yalnızca Heltec Wireless Stick Lite V3 içindir. Yükleme sırasında USB bağlantısını kesmeyin.
Bu tarayıcı Web Serial desteklemiyor. Windows/macOS/Linux üzerinde güncel Chrome veya Edge kullanın. Web Installer için HTTPS üzerinden açılan sayfa gerekiyor.

İlk kurulum / First setup

Cihaz ilk açılışta kayıtlı Wi-Fi ayarı bulamazsa kurulum ağı oluşturur.

Wi-Fi ağı: TA1FM-APRS-SETUP
AP şifresi: 1234567890
Panel: http://192.168.4.1

Varsayılan yönetici: admin · Parola: 1234567890. Bu herkese açık örnek parolayı kaynak kodda değiştirip yeniden derlemek gerekir; paneli internete açmayın.
